🔍 SearchClient - Ejemplos de Uso

Este archivo muestra diferentes formas de usar el módulo SearchClient.

1️⃣ Búsqueda Básica

Configuración mínima con valores por defecto.

Mínimo 2 caracteres 
const searchClient = new SearchClient({
    endpoint: '/api/v1/search/variantes',
    inputElement: document.getElementById('search-basic'),
    resultsContainer: document.getElementById('search-results-1'),
    hiddenInput: document.getElementById('hidden-basic')
});

2️⃣ Con Filtros Dinámicos

Aplicar filtros por tipo de parte y actualizar en tiempo real.

let searchWithFilters;

function initFilteredSearch() {
    searchWithFilters = new SearchClient({
        endpoint: '/api/v1/search/variantes',
        inputElement: document.getElementById('search-filtered'),
        resultsContainer: document.getElementById('search-results-2'),
        filters: { tipo_codigo: '' },
        onSelect: (item) => {
            const info = document.getElementById('selected-info-2');
            info.textContent = `Seleccionado: ${item.display_text}`;
            info.classList.remove('d-none');
        }
    });
}

function applyFilter(type) {
    searchWithFilters.updateFilters({ tipo_codigo: type });
}

3️⃣ Renderizado Personalizado

Personalizar la forma en que se muestran los resultados.

const customSearch = new SearchClient({
    endpoint: '/api/v1/search/variantes',
    inputElement: document.getElementById('search-custom'),
    resultsContainer: document.getElementById('search-results-3'),
    renderItem: (item, index) => {
        const div = document.createElement('button');
        div.type = 'button';
        div.className = 'list-group-item list-group-item-action';
        div.innerHTML = `
            

                
                

                    ${item.codigo_variante}
                    
${item.detalle}
                

                ${item.tipo_codigo}
            

        `;
        return div;
    }
});

4️⃣ Con Callbacks y Validación

Ejecutar lógica adicional al seleccionar un item.

const callbackSearch = new SearchClient({
    endpoint: '/api/v1/search/variantes',
    inputElement: document.getElementById('search-callback'),
    resultsContainer: document.getElementById('search-results-4'),
    hiddenInput: document.getElementById('hidden-callback'),
    onSelect: (item) => {
        // Validar
        if (item.tipo_codigo === 'MO') {
            alert('No se puede agregar mano de obra aquí');
            callbackSearch.clear();
            return;
        }

        // Habilitar botón
        document.getElementById('btn-submit').disabled = false;

        // Log
        const log = document.getElementById('callback-log');
        log.innerHTML += `
✅ ${new Date().toLocaleTimeString()}:
                          Seleccionado ID ${item.id}
`;
    }
});

📚 Información Técnica

Métodos Disponibles:
  • updateFilters(newFilters) - Actualizar filtros
  • clear() - Limpiar selección
  • destroy() - Destruir instancia
Navegación por Teclado:
  • ↓ - Siguiente resultado
  • ↑ - Resultado anterior
  • Enter - Seleccionar
  • Esc - Cerrar
